How this repository works
The whole website is a single file, `index.html`. The images and video samples are embedded inside it, so there is nothing else to install or build. It is hosted with GitHub Pages.
Fonts load from Google Fonts (Inter)
Works on desktop and mobile
Has a white and black theme, with a switch in the top menu
Updating the site
Replace `index.html` in this repository with the new version.
Commit the change.
GitHub Pages republishes the site within a couple of minutes.
